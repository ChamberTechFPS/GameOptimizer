# Valorant — settings card

Valorant stores settings **server-side** (Riot cloud), so no file can be applied. Set these in-game:

## Video
- Display mode: Fullscreen · Resolution: native @ max Hz
- Material / Texture / Detail / UI quality: **Low**
- Vignette off · VSync **off** · Anti-aliasing: MSAA 2x (or off) · Anisotropic: 1x
- Improve clarity off · Bloom off · Distortion off · Cast shadows off

## Stats overlay
- Show FPS + network round trip (Settings → Video → Stats)

Vanguard requires **Secure Boot + TPM** — the Chamber Playbook keeps both on.
